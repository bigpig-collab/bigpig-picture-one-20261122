One strawberry. One ingredient. One taste.

This entry is an extreme macro photograph of a single perfect ripe
strawberry filling the frame: glossy red skin glistening with fresh
juice, a droplet sliding down its side, tiny seeds catching warm
golden light, and fresh green leaves at the top against a dark
charcoal background. Nothing else is in the picture — no plate, no
hands, no other food — so the whole flavour of the image comes from
that one berry.

## Run

```sh
python3 main.py
```

The program copies `entry.png` byte-for-byte to `/output/entry.png`
(or to the directory set by `MAKEFUN_OUTPUT_DIR`). It uses only the
Python standard library.
